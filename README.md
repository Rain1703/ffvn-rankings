# FFVN Rankings — bản demo

Mở `index.html` để xem website.

## Tính năng
- Top 100 team, tự sắp xếp theo điểm.
- Tìm kiếm team.
- Form cộng đồng gửi team và điểm đề xuất.
- Admin duyệt/từ chối yêu cầu.
- Admin chỉnh điểm trực tiếp.
- Admin xóa team.
- Dữ liệu demo dùng localStorage nên chạy ngay không cần server.

## Admin demo
Mở `admin.html`
Mật khẩu: `ffvn2026`

## Khi đưa lên Internet
Bản này là prototype frontend. Để dùng thật, cần thay localStorage bằng database (ví dụ Supabase), dùng đăng nhập admin phía server, upload logo/bằng chứng vào storage và bảo vệ API.
